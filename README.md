# Brasas y Raíces 🔥

**Prototipo jugable v0.2** — aventura original de exploración, supervivencia ligera, construcción y criaturas elementales.

## Jugar
Una vez habilitado GitHub Pages, juega desde el navegador en:
https://blasterg10.github.io/Brasas-Y-Raices/

No requiere APK, backend, dependencias ni cuentas externas. El juego está diseñado para pantallas táctiles y también acepta teclado.

## Controles
- Flechas táctiles o WASD/flechas del teclado para caminar.
- **A · Interactuar**: recoge madera y bayas, habla con el entorno y reconstruye el refugio.
- **Mochila**: consulta tus recursos.
- **Equipo**: consulta las criaturas vinculadas.
- En combate: Chispa, Golpe, Esfera de vínculo, Baya o Retirarse.
- **Guardar**: guarda la partida localmente en el navegador.

## Primera misión
Reúne **5 maderas** y **2 bayas**, regresa al refugio y reconstruye el hogar. Explora la hierba alta para encontrar criaturas. Debilítalas y usa una Esfera de vínculo para intentar sumarlas a tu equipo.
